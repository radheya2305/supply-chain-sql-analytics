# Data

`run_all.py` downloads the seven Olist CSV files into this folder on first run.

If the download fails, get the dataset manually from
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce (free Kaggle account),
unzip it, and copy these files here:

- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- olist_customers_dataset.csv
- olist_order_reviews_dataset.csv
- product_category_name_translation.csv

The CSV files are not committed to GitHub (see .gitignore).
